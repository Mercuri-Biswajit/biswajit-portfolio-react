## 2024-05-19 - Keyboard Accessibility for Complex Flex Containers
**Learning:** For complex flex-container interactive elements (like `.project-card` and `.hpc-card`) using `tabIndex={0}`, default focus states can be cut off or visually inconsistent due to `overflow: hidden`.
**Action:** Apply explicit `:focus-visible` styles to the inner visual wrapper (e.g., `.project-card-inner`) using an appropriate `outline-offset` and `var(--color-accent)`, and set `outline: none;` on the outer container's `:focus-visible` state to prevent double outlines and clipping. For elements like `.hpc-card` that might not have an inner wrapper suitable for outlines, ensuring the outline and `outline-offset` are appropriately sized directly on the element can bypass some `overflow: hidden` issues if the container isn't constrained severely.
