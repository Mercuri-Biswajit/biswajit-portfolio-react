
## 2024-06-18 - Keyboard Focus on Complex Cards with Hidden Overflow
**Learning:** For complex interactive card elements (like `.project-card`) that use `tabIndex={0}` and have `overflow: hidden` on their inner wrappers to contain images and gradients, applying a standard `outline` or `box-shadow` on the inner wrapper without an `outline-offset` causes the focus ring to be clipped and invisible. Additionally, if the outer container is the one receiving focus, applying focus directly there might result in a sub-optimal visual layout, or a double outline if the browser default isn't explicitly removed.
**Action:** Remove the browser default outline on the outer focusable container (`:focus-visible { outline: none; }`). Then, target the inner visual wrapper using an adjacent selector or descendant selector (e.g., `.card:focus-visible .card-inner`) and apply an explicit `outline` combined with a positive `outline-offset` (e.g., `outline-offset: 4px;`) to draw the focus ring outside the clipping boundary. Use the design system's accent color (e.g., `var(--color-accent)`) for consistency.
