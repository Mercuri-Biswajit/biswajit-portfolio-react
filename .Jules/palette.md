## 2025-02-12 - Accessibility of focus rings on `overflow: hidden` elements
**Learning:** When complex flex-container interactive elements like `.project-card` or `.hpc-card` use `tabIndex={0}` to act as buttons, standard `:focus-visible` browser outlines can be completely clipped/hidden if the parent has `overflow: hidden` and no padding. This makes keyboard navigation inaccessible as users cannot see what element has focus.
**Action:** Always verify keyboard focus visibility for custom cards. Apply explicit `:focus-visible` styles with an appropriate `outline-offset: -2px` (inset) or target the inner visual wrapper (`.project-card-inner`) instead, ensuring that an explicit outline using the project's accent color (`var(--color-accent)`) remains visible. Apply `outline: none;` on the parent to avoid double rings.
