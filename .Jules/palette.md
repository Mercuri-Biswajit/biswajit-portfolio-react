## 2024-05-24 - Interactive Component Focus States
**Learning:** Some custom cards (`ProjectCard`, `HomeProjectCard`) are explicitly `tabIndex={0}` but the global CSS reset `.project-card:focus-visible` or similar isn't defined explicitly enough or lacks explicit `outline: 2px solid var(--color-accent)`. The global reset only does `:focus-visible { outline: 2px solid var(--color-primary); }` but maybe not visually standing out or cut off by `overflow: hidden`.
**Action:** Need to check keyboard focusability. Wait, the prompt memory mentions: "For complex flex-container interactive elements (like `.project-card` and `.hpc-card`) using `tabIndex={0}`, default focus states might be cut off due to `overflow: hidden`. Apply `:focus-visible` styles to the inner visual wrapper (e.g., `.project-card-inner`) or use an appropriate `outline-offset` to ensure visibility. To prevent double outlines, explicitly set `outline: none;` on the outer container's `:focus-visible` state." Also, "use var(--color-accent) for explicit :focus-visible outlines."
